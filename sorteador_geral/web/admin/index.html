Prêmios e probabilidades

Nome: o prêmio exibido. Ícone: símbolo que o acompanha. Peso: valor salvo exatamente como digitado; se os ativos somarem 100, corresponde à porcentagem. Chance real: porcentagem calculada com os pesos. Ativo: permite sair no sorteio. Excluir: remove o prêmio.

Exemplo: pesos 45 e 5 somam 50; as chances reais são 90% e 10%. Pesos iguais dão chances iguais. Itens inativos não participam. Se todos os pesos ativos forem 0, as chances serão iguais. Os valores digitados são preservados ao salvar e reiniciar. A chance real é calculada à parte. Clique em Salvar tudo para aplicar.

TWITCH

Anunciar sorteio e resultados no chat

Ativo ao conectar. Você pode silenciar aqui; a escolha é salva automaticamente.

Usa EventSub WebSocket. Exige Client-ID + OAuth com scope user:read:chat.

Gere um User Access Token em Twitch Token Generator, usando Custom Scope Token com user:read:chat e user:write:chat. Copie o Access token e o Client ID do mesmo resultado. chat:read/chat:edit são permissões antigas de IRC e não substituem essas.

Opcional: consulta a Twitch para conferir o token, mostrar suas permissões e preencher o Client ID sem digitar.

Diagnóstico da conexão

Uma única autorização para ler o chat, enviar mensagens e obter avatares. Use user:read:chat para leitura e user:write:chat para escrita.

KICK

Anunciar sorteio e resultados no chat

Ativo ao conectar. Você pode silenciar aqui; a escolha é salva automaticamente.

Receber chat e inscrições

A conexão direta lê o chat público sem login ou túnel. Depende do serviço usado pelo site da Kick; se estiver indisponível, o erro será informado sem ativar simulação.

Opções avançadas da conexão direta

Se a identificação automática retornar HTTP 403, informe chatroom.id e id do canal em https://kick.com/api/v1/channels/SEU_CANAL, aberto no seu navegador. Não é o ID do aplicativo nem seu nick.

Autorizar conta para enviar mensagens

Use sua conta atual ou uma conta de bot separada. As mensagens são enviadas com o nome da conta autorizada. Não precisa de Kicklet. Ler o chat no modo direto não depende desta autorização.

Use o Client ID do aplicativo, não seu nick ou nome do canal. Copie o Client ID e o Client Secret em Kick → Configurações → Desenvolvedor.

Cadastre exatamente esta URI no aplicativo da Kick. Para uso local, recomendamos http://localhost:8777/api/oauth/kick/callback. Se mantiver 127.0.0.1, o programa aplica a correção oficial ao link de autorização.
